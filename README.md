# Summer Moogle Yuffie - FF7 Rebirth 1.005 Fix

Short compatibility guide for using Summer Moogle Yuffie with FINAL FANTASY
VII REBIRTH version 1.005 without redistributing the original mod.

1. Download [Summer Moogle Yuffie](https://www.nexusmods.com/finalfantasy7rebirth/mods/740)
   from its original author.
2. Install the original `.pak`, `.utoc`, and `.ucas` files.
3. Follow the
   [Yuffie patch instructions](https://github.com/dieter1199/FF7-Rebirth-1.005-Legacy-Mod-Patches/blob/main/docs/yuffie-summer-moogle.md).

The shared repository provides the PowerShell helper, requirements, restore
instructions, and guides for other supported legacy mods:

[FF7 Rebirth 1.005 Legacy Mod Patches](https://github.com/dieter1199/FF7-Rebirth-1.005-Legacy-Mod-Patches)

No original or patched mod assets are included in this repository.
